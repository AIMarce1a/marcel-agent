# Environment Variables Reference

This is the authoritative reference for Marcel Agent environment variables. It
preserves the complete catalog formerly maintained in the root `.env.example`;
the root file is intentionally only a safe onboarding starter. Values shown
below are documentation placeholders or defaults, never credentials. Keep
secrets in a private `.env` and consult the focused examples in `examples/env/`
for common integrations.

For the full provider and runtime catalog, see the maintained reference in
[`website/docs/reference/environment-variables.md`](../../website/docs/reference/environment-variables.md).
